# Problem 1: Three ways to sum to n

Run each file with Node:

```
node a.js
node b.js
node c.js
```

| File | Approach | Time | Space |
|------|----------|------|-------|
| `a.js` | Loop | O(n) | O(1) |
| `b.js` | Gauss formula | O(1) | O(1) |
| `c.js` | Divide and conquer | O(n) | O(log n) |

No output means all checks passed. A failed check prints `Assertion failed`.

Each file ends with a few `console.assert` checks. Feel free to change or add to them.
